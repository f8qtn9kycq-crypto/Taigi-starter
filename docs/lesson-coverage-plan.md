# 生活實用覆蓋與新增課程決策

## 判準

課程順序以初學者最常遇到、最能立刻完成小任務的情境為先：打招呼與
禮貌、身分與數量、吃飯購物、問路交通、時間天氣、健康與求助，最後才
進入家庭、社區、工作和綜合對話。每課維持 Busuu 式短課程骨架：
Hear → See → Say → Recall → Use；每課有一個主要生活任務，並列出至少
三個可播放的目標詞。

本階段採「無教師阻塞」模式：沒有臺語教師時，仍可用教育部公開資源、既有
辭典／教材、人工比對與基本人工檢查快速測試產品；`teacherReview` 仍保留為
pending，不能寫成教師已核准。產品文案固定標示「初期測試版本，採常見生活
用語；部分字詞可能因地區與使用習慣不同」。

教育部「咱來學臺灣閩南語」教材本身也按發音、詞彙、語句與文章逐步安排，
因此本產品先用來源可追溯的詞彙建立可靠的短課，再逐步補上完整情境句，
不把沒有來源或沒有原始音檔的對話假裝成已完成教材。

目前 release candidate 是 1–20 課、58 個目標詞和 58 個教育部原始 MP3。
每個詞都有臺羅、POJ、漢字、雙語意思與文化註記；每課都有雙語標題、主要
目標、生活任務和五段 stage plan。課卡也直接列出整課目標詞，避免只看到
第一個詞就誤判課程內容。

## 下一批只在來源齊備時新增

仍有四個高價值缺口：廁所／所在、電話與聯絡、緊急或更明確的求助、住宿。
它們不應以 placeholder 音檔或推測 POJ 先加入；新增前必須逐詞取得教育部
canonical page、授權、原始 MP3、未修改檔案與可核對的 POJ。若來源只足以
支援詞彙，不足以支援完整對話，就先標成下一個 source-backed package，並
在 Use 階段誠實標示為文字轉移任務，而不是宣稱已提供完整對話音檔。

這次先把 19（禮貌交換）和 20（求助與放慢）納入，是因為它們直接補上最常
阻礙初學者實際使用的「請問／多謝／失禮／請人幫忙／請講慢」；Say completion
gate、真正的 Recall retrieval check、Use micro-transfer task 和 B08
真人 mobile review 仍是後續教學互動 PR，不與本次來源修復混在一起。

## 明確不做

單人 MVP 目前不做教師帳號／審核後台、多人協作流程、完整 CMS、自動發布
系統、複雜資料庫、自己訓練語音模型、自由聊天式 AI tutor，也不一次建立
A0 到 B2 或所有課型。先用真實小課驗證有人學、能完成、願意回來，再決定
是否值得蓋更大的內容工廠。
